CleanMinimap 1.6.2 fixed build (WoW 3.3.5a)
 - Anchored player buffs, debuffs, consolidated buffs and temporary enchants to the minimap cluster.
 - Kept native aura icon sizes while anchoring all aura frames to the scaled minimap edge.
 - Re-applied aura anchors after Blizzard frame management and aura/enchant transitions.

CleanMinimap 1.6.3 fixed build (WoW 3.3.5a)
 - Moved the Dungeon Finder eye into the icon column below the battleground icon, sized by the Icon size option.
 - Counter-scaled the Dungeon Finder status popup so it no longer inherits the minimap scale.

CleanMinimap 1.6.4 fixed build (WoW 3.3.5a)
 - Kept the square border at its 100% thickness when the minimap scale is above 100%.
 - Removed the box behind the zone name in square mode.

CleanMinimap 1.6.5 fixed build (WoW 3.3.5a)
 - Kept the map's gap to the screen's right and top edges constant at every scale; the cluster now wraps the map.
 - Anchored the zone name just above the map/border, centred, with no box, in both shapes.
 - Replaced Blizzard's round border with a thin black ring (texture/Ring1-5.tga) that keeps its 100% thickness.
 - Added "Show border" and "Minimap opacity" options (opacity is full indoors).
 - Moved the Dungeon Finder popup to UIParent so minimap scale/opacity never apply to it.
 - Mouse-wheel zoom and zone-name click now work in round mode too.

CleanMinimap 1.6.6 fixed build (WoW 3.3.5a)
 - Kept the minimap fully opaque whenever it shows an indoor-style map (cities such as Orgrimmar, not just buildings), fixing the blank map with opacity below 100%.

CleanMinimap 1.6.7 fixed build (WoW 3.3.5a)
 - Showed the calendar button in its own slot at the bottom of the icon column, sized by Icon size, with a "Show calendar" option to hide it.

CleanMinimap 1.6.8 fixed build (WoW 3.3.5a)
 - Scaled other addons' round minimap buttons with the Icon size option, keeping their positions; "Resize addon minimap buttons" turns it off.

CleanMinimap 1.6.9 fixed build (WoW 3.3.5a)
 - Gave all addon minimap buttons one size and put them on the border at their addon's angle, draggable round it; option renamed "Tidy addon minimap buttons".

CleanMinimap 1.7.0 fixed build (WoW 3.3.5a)
 - Moved Blizzard's tracking, mail, battleground, Dungeon Finder and calendar icons onto the border with the addon buttons: one size for every icon, rings restored, each draggable round the border with saved positions.

CleanMinimap 1.7.1 fixed build (WoW 3.3.5a)
 - Drew the border, north marker, clock, zone name and every icon a strata above the map, so other addons' map markers slide under the border and never cover an icon.
 - Fixed the LibDBIcon "quadTable" error when dragging an addon's minimap button in round mode: GetMinimapShape() now returns "ROUND" instead of "CIRCULAR".

CleanMinimap 1.7.2 fixed build (WoW 3.3.5a)
 - Took over dragging for other addons' minimap buttons so every icon follows the cursor the same way at any minimap scale, and saved where each button is left by name.

CleanMinimap 1.7.3 fixed build (WoW 3.3.5a)
 - Stopped moving the game's map to the player's zone on zone changes while the world map is open, which snapped it back during flights while browsing; Blizzard's world map resets it when it closes.
